03

何謂知覺（perception）

WHAT IS PERCEPTION?
[ 3 POINTS ]
+[ 01／DEFINITION ]

定義

知覺是人們將感官印象組織、解讀並賦予意義的過程。同一個對象，不同人可以有截然不同的知覺；行為依據的是知覺到的世界，不是客觀事實。

+[ 02／IMPORTANCE ]

重要性

人們根據對事實的知覺，而非事實本身來決定行為。管理上重要的不是客觀現實，而是員工如何知覺薪資、主管與制度。

+[ 03／FACTORS ]

影響因素

知覺受知覺者、目標物和情境因素影響。三類因素在知覺形成的瞬間交互作用，任何一環改變，看見的樣貌就會不同。

04

影響知覺的因素

FACTORS THAT INFLUENCE PERCEPTION
[ 3 SOURCES ]
+[ 01／PERCEIVER ]

知覺者

個人特質如態度、人格、動機、興趣、過往經驗和期望影響知覺。期望尤其強大：預期對方偷懶，便容易把中性行為解讀為怠惰。

+[ 02／TARGET ]

目標物

目標物通常不是單獨存在的，目標物與背景的關係影響知覺，人們常將距離相近或類似的事物歸為同類。新奇、移動、聲音、大小等屬性，決定了目標物被注意到的機率。

+[ 03／CONTEXT ]

情境

出現的時間點、地點、光線、溫度等情境因素影響知覺。同一個人出現在夜店與教室，引發的知覺截然不同——情境改變了解讀。

歸因理論

ATTRIBUTION THEORY
[ INTERNAL vs. EXTERNAL ]
+[ 01／DEFINITION ]

定義

歸因理論解釋我們如何判斷他人行為，是由內在或外在因素引起。對行為原因的判斷，決定了後續的獎懲與互動方式。

+[ 02／INTERNAL ]

內在因素

可由個人掌控的行為原因，例如能力不足、不夠努力或個性使然；內歸因常伴隨究責。

+[ 03／EXTERNAL ]

外在因素

迫於外部環境而產生的行為原因，例如塞車、制度限制或運氣不佳；外歸因傾向寬容以對。

歸因理論的要素

DISTINCTIVENESS ── CONSENSUS ── CONSISTENCY
[ 3 ELEMENTS ]
[ 01／DISTINCTIVENESS ]

特殊性

指個人行為在不同情境下是否有所不同。如果一個人在特定情境中有特殊表現，表示該情境具高特殊性。

如果小明上早上九點的 OB 課和 HRM 課都會遲到，行為一致，特殊性低；只在 OB 課遲到而不在 HRM 課遲到，特殊性高。

[ 02／CONSENSUS ]

共同性

指其他人在相同情境下，是否也有相同行為。如果大多數人都一樣，則共同性高，反之則低。

如果小明和小花都在早上九點的 OB 課遲到，共同性高；只有小明遲到，其他人準時，共同性低。

[ 03／CONSISTENCY ]

一致性

指個人在不同時間下遇到相同情境時，行為是否相同。行為在多個時間點都一致，表示一致性高。

如果小明不論 OB 課是早上九點或下午兩點都遲到，一致性高；只在早上九點遲到，一致性低。

基本歸因誤差

FUNDAMENTAL ATTRIBUTION ERROR
[ BIAS／01 ]
+[ 01／DEFINITION ]

定義

判斷他人行為時，低估外在因素、高估內在因素的傾向。評價他人時，性格解釋往往壓過情境解釋，即使情境證據明顯。

+[ 02／EXAMPLE ]

例子

業務主管常把業績衰退歸咎於業務員的怠惰，較少歸因於競爭者的創新產品或市場景氣等外部因素。

+[ 03／IMPACT ]

影響

可能導致對他人行為的錯誤判斷。對部屬的錯誤內歸因會侵蝕信任，也讓真正的制度問題被忽略。

自利性偏差

SELF-SERVING BIAS
[ BIAS／02 ]
+[ 01／DEFINITION ]

定義

將模糊含混的訊息往正面方向解讀，接受正面回饋，否認負面回饋。成功歸功自己、失敗歸咎外界，是自利性偏差的典型樣貌。

+[ 02／IMPACT ]

影響

可能導致對自身行為和能力的錯誤評估。團隊成員彼此推責時，績效檢討容易流於形式。

+[ 03／MANAGEMENT ]

管理啟示

管理者應意識到這種偏差，以更客觀地評估自己和他人。回饋面談時提供具體行為證據，可降低當事人防衛性的解讀。

選擇性知覺

SELECTIVE PERCEPTION
[ BIAS／03 ]
+[ 01／DEFINITION ]

定義

人們傾向注意突出的特質，影響對人事物的知覺。我們看見的常是想看見的：突出、與己相關的訊息最容易被接收。

+[ 02／REASON ]

原因

無法全面關注周遭事物，根據興趣、背景、經驗和態度選擇。注意力有限是天生限制，選擇性本身無可避免，問題在於未經檢核。

+[ 03／IMPACT ]

影響

可能導致在模糊情境下形成不可靠的推斷。例如主管巡視時只注意到犯錯的部門，忽略一路穩定的團隊。

月暈效果

HALO EFFECT
[ BIAS／04 ]
+[ 01／DEFINITION ]

定義

根據個人單一特質形成整體印象的傾向。單一亮點或污點像光暈一樣，渲染了其他所有面向的評價。

+[ 02／EXAMPLE ]

例子

可能因聰明才智、社交能力或外型而對整體印象產生偏見。面試研究顯示，衣著與談吐等表面線索常左右整體評價。

+[ 03／MANAGEMENT ]

管理啟示

管理者應謹慎，不要從小線索斷然推論。績效評估時分項逐一評分、再行彙總，可減少月暈效果。

對比效果

CONTRAST EFFECT
[ BIAS／05 ]
+[ 01／DEFINITION ]

定義

最近遇到的其他人會影響對眼前這個人的評價。評價從來不是在真空中進行：前一位表現的高低，改變了眼前這位的分數。

+[ 02／IMPACT ]

影響

可能導致對個人能力或表現的錯誤評估。面試順序效應是典型例子——排在傑出者之後的人容易被低估。

+[ 03／CAUTION ]

注意事項

在評估他人時應考慮到這種效果，避免不公平比較。集中在同一時段評分、使用固定評分基準，可降低對比效果。

刻板印象

STEREOTYPING
[ BIAS／06 ]
+[ 01／DEFINITION ]

定義

根據對某團體的知覺來判斷個人的傾向。以群體的平均印象取代對個人的認識，是認知上的省力捷徑。

+[ 02／IMPACT ]

影響

可能導致對個人能力或特質的錯誤假設。刻板印象威脅（stereotype threat）還會反過來影響被貼標籤者的實際表現。

+[ 03／MANAGEMENT ]

管理啟示

管理者應意識到刻板印象的存在，努力客觀評估每個人。以具體行為與實績作為人事決策依據，是對抗刻板印象最實際的方式。

人際知覺在組織中的應用

PERSON PERCEPTION IN ORGANIZATIONS
[ 3 AREAS ]
+[ 01／INTERVIEW ]

甄選面談

主試者常在面談開始 4 至 5 分鐘內就形成整體印象，可能影響最終決策。第一印象一旦形成，後續資訊常被用來確認而非修正它。

+[ 02／EXPECTATION ]

績效期望

自我實現預言（self-fulfilling prophecy，又稱比馬龍效應 Pygmalion effect）顯示個人行為會受到他人期望影響。主管期望高，部屬表現往往真的更好——期望透過日常互動自我實現。

+[ 03／APPRAISAL ]

績效評估

主觀評估可能受到各種偏差影響，如選擇性知覺、對比效果、月暈效果等。評估者訓練與多元評量來源，能稀釋單一知覺偏差的影響。

補充研究：第一印象不會隨相處自動修正

FIRST IMPRESSIONS DO NOT SELF-CORRECT
[ PERSONNEL PSYCH 2026 ]
204 SAMPLES
匯總 204 個獨立樣本的統合分析：第一印象形成後不隨相處自動修正，一個月後與後續印象的相關仍達 .51，各時間區段之間無顯著差異。
+[ 01／CONCEPT ]

總評式的結構

職場第一印象收斂為整體性的總評，能力與溫暖等面向並非各自獨立運作。總評形成後會滲透後續的面試評分、績效評等與人際對待，月暈效果（halo effect）在相識初期即啟動。

+[ 02／FINDINGS ]

主要數據

  • 一個月後，第一印象與後續印象的相關為 .51，各時間區段之間無顯著差異
  • 溝通線索的預測力 .52，高於外表 .31 與履歷等內容線索 .23
  • 印象對後續結果的預測力由 .48 隨時間衰減至 .28
+[ 03／MECHANISM ]

為什麼不會修正

確認偏誤（confirmation bias）使評估者偏向蒐集支持既有印象的訊息；自我實現預言（self-fulfilling prophecy）使對待方式引出符合預期的行為。相處增加熟悉，修正需要與預期直接矛盾的明確證據——開場影片正是這種條件。

+[ 04／IMPLICATIONS ]

意涵

  • 評估端：降低偏誤需靠制度設計，包括結構化面談（structured interview）、標準化評分準則與多位評分者
  • 受評端：溝通線索的權重最高，表達與互動的準備報酬高於外表與履歷
Yang, J., Swider, B. W., Lu, B., Wang, K., & Harris, T. B. (2026). First impressions at work: A meta-analytic review. Personnel Psychology. 提前線上出版。https://doi.org/10.1111/peps.70037

有限理性

BOUNDED RATIONALITY
[ SIMON ]
+[ 01／DEFINITION ]

定義

人類在處理複雜問題時，傾向將其簡化到容易理解的程度。完全理性要求掌握所有資訊與選項，現實中幾乎不可能。

+[ 02／FEATURES ]

特點

建立簡化模型，在有限範圍內進行理性決策，依序檢視方案，遇到第一個夠好的就停下。

+[ 03／RESULT ]

結果

常選擇夠好的（suboptimal decision）而非最佳方案。滿意即可不是懶惰，而是資訊、時間與運算能力有限之下的理性。

有限理性的展現之一是滿意即可（satisficing）：尋求足夠好、可接受但未必最佳的解

直覺決策

INTUITIVE DECISION MAKING
[ FAST＋RISKY ]
+[ 01／DEFINITION ]

定義

基於經驗的無意識決策過程。直覺源自長期經驗累積的組型辨識，快而不必然錯。

+[ 02／FEATURES ]

特點

快速、受情感主導，能將看似不相關的資訊整合。在時間壓力大、資訊模糊的情境中，直覺常是唯一可用的引擎。

+[ 03／APPLICATION ]

應用

適用於提出假設，但需要客觀數據和理性分析來驗證。最佳實務：讓直覺出題、讓證據閱卷。

決策中常見的偏差及錯誤（一）

COMMON BIASES ＆ ERRORS
[ 3 BIASES ]
[ 01／OVERCONFIDENCE ]

過度自信

OVERCONFIDENCE BIAS

對自己和他人能力的過度自信。研究顯示，智力與人際能力愈弱的人，愈容易高估自己的能力與表現。

反之可能為冒牌者症候群（imposter syndrome）。

[ 02／ANCHORING ]

定錨偏差

ANCHORING BIAS

被最初訊息鎖住，難以根據後續訊息調整。談判中先開價者往往佔優勢，正是善用了定錨效果。

[ 03／CONFIRMATION ]

肯證偏差

CONFIRMATION BIAS

傾向蒐集支持自己想法的資訊，忽視相反證據。人們對支持性訊息照單全收，卻用放大鏡檢視相反的資訊。

現成偏差和升高承諾

AVAILABILITY ＆ ESCALATION
[ 2 BIASES ]
[ 01／AVAILABILITY ]

現成偏差

AVAILABILITY BIAS

傾向利用手邊現成的資訊進行判斷。鮮明、情緒強烈或近期發生的事件最容易被提取，例如空難新聞使人高估飛航風險。

管理啟示

定期評估已投入成本，考慮是否值得繼續投資，避免沉沒成本（sunk cost）。

隨機誤差和風險規避

RANDOMNESS ERROR ＆ RISK AVERSION
[ 2 BIASES ]
[ 01／RANDOMNESS ]

隨機誤差

RANDOMNESS ERROR

相信可以預知隨機事件結果，可能導致錯誤決策。迷信與儀式化行為，常是把隨機結果錯認為有規律可循。

[ 02／RISK AVERSION ]

風險規避

RISK AVERSION

偏好確定狀況，不喜歡不確定結果。多數人寧可接受確定的較小報酬，也不願冒險爭取期望值更高的結果。

[ 03／IMPACT ]

影響

可能導致錯失機會或做出不理性決策。薪酬設計上，風險規避使員工偏好固定薪資勝於變動獎金。

後見之明偏差

HINDSIGHT BIAS
[ BIAS ]
+[ 01／DEFINITION ]

定義

事件發生後，誤以為事前就已精準預知結果的傾向。事後看來一切理所當然，是因為結果已知、線索被重新編排。

+[ 02／IMPACT ]

影響

可能導致對過去決策的錯誤評估和學習。它讓人高估自己的預測能力，阻礙從經驗中誠實學習。

+[ 03／MANAGEMENT ]

管理啟示

在評估過去決策時，應考慮當時可用的資訊和環境。以決策當下的品質、而非事後的結果來評價決策。

32

降低偏誤與錯誤的方法

REDUCING BIASES AND ERRORS
[ 4 STRATEGIES ]
[ 01／FOCUS ON GOALS ]

聚焦目標

沒有目標就無法理性：不知道需要什麼資訊、分不清資訊是否相關，也難以在方案間取捨。明確的目標讓決策更容易，並可剔除與自身利益不符的選項。

[ 02／DISCONFIRM ]

尋找反證資訊

主動尋找與自身信念、假設相矛盾的資訊，是對抗過度自信、肯證偏差與後見之明偏差最有效的方法之一；公開思考自己可能錯在哪裡，能挑戰自以為聰明的傾向。

[ 03／NO FALSE MEANING ]

不要在隨機事件中找意義

受過訓練的心智習慣尋找因果，找不到理由時常會自行發明。必須接受生活中有些事件不可控制，並自問：模式是有意義的，還是只是巧合。

[ 04／MORE OPTIONS ]

增加選項

最終決策的品質，不會超過選項集合中最好的那一個。增加並多樣化決策選項、發揮創意產生更多元的方案，找到出色選項的機會就更大。

道德決策準則

THREE ETHICAL DECISION CRITERIA
[ 3 CRITERIA ]
[ 01／UTILITARIANISM ]

功利主義

考量決策結果，目的是為多數人謀福利。

此觀點主導商業決策，與理性、效率、生產力和高獲利等目標一致；但組織的最佳利益也可能被用來合理化裁員等有爭議的行動。

[ 02／RIGHTS ]

權益

強調不可妨害他人的基本自由權及法定權利，例如隱私、言論自由與正當程序；吹哨者保護正是以權益準則為基礎。

[ 03／JUSTICE ]

公平正義

要求訂定並強制實施公平合理的規則，讓利益與成本的分配符合公平；同工同酬的主張即源於此準則。

行為道德與組織決策

BEHAVIORAL ETHICS
[ WHY GOOD PEOPLE
DO BAD THINGS ]
+[ 01／DEFINITION ]

定義

分析人們在面對道德困境時的反應行為——研究為什麼好人仍會做出壞事。多數人重視道德，但道德判斷深受情境壓力與框架影響。

+[ 02／CHALLENGE ]

挑戰

人們不一定遵守組織或個人的道德標準，道德行為在不同情境間變動很大。時間壓力、業績目標與從眾心理，都會讓道德標準悄悄鬆動。

+[ 03／IMPROVEMENT ]

改善方法

鼓勵道德對話、注意道德盲點、強調文化對道德決策的重要性。把道德議題放進日常決策的檢核清單，而不是等出事才討論。
