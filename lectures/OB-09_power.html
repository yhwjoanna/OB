權力的定義與本質

WHAT IS POWER?
[ DEFINITION ]
權力（power）指A擁有能影響B之行為的能力，致使B依照A所希望的去做。權力可以存在而不被使用。
+ [ 01／CAPACITY ]

權力是一種潛能

A CAPACITY

權力是影響力的潛在能力，不必實際行使即可存在。一個人可以擁有權力，卻選擇不使用。權力最重要的面向，是它作為一種蓄而不發的能量。

+ [ 02／DEPENDENCY ]

權力的本質：依賴性

DEPENDENCY

權力最重要之處在於它的依賴性（dependency）。只有在A控制B想要的事物時，A對B才有權力。依賴性愈大，權力愈大——這是貫穿本章的核心邏輯。

權力與領導的區別

POWER VS. LEADERSHIP
[ 3 CONTRASTS ]
+ [ 01／GOALS ]

目標一致性

GOAL COMPATIBILITY

領導需要領導者與被領導者目標一致；權力並不需要目標一致，只要有依賴性存在即可。權力可以被用來服務組織，也可以被用來服務私利。

+ [ 02／DIRECTION ]

影響方向

DIRECTION OF INFLUENCE

領導研究著重由上往下對部屬的影響力；權力的研究則涵蓋向上、向下與橫向等各種影響方向。

+ [ 03／FOCUS ]

研究重點

RESEARCH EMPHASIS

領導方面的研究多強調領導者的風格；權力的研究則聚焦於取得順從的戰術與依賴關係。

權力的基礎來源

BASES OF POWER
[ 2 CATEGORIES ]
+ [ 01／FORMAL ]

正式權力

FORMAL POWER

來自組織中的正式職位，包括強制權、獎賞權與合法權三種類型。職位變動時，正式權力隨之而來、也隨之而去。

+ [ 02／PERSONAL ]

個人權力

PERSONAL POWER

來自個人特質和專業知識，及他人的尊敬與讚賞，包括專家權與參考權兩種類型。個人權力附著在人身上，離開職位依然存在。

正式權力的三種類型

FORMAL POWER
[ 3 TYPES ]
+ [ 01／COERCIVE ]

強制權

COERCIVE POWER

基於恐懼、害怕，個體擔心若不順從可能會帶來負面後果，例如懲處、調職或解僱。也包括扣留關鍵資訊等隱性手段。

+ [ 02／REWARD ]

獎賞權

REWARD POWER

人們順從乃因為他們預期這樣可以帶來好處，例如加薪、升遷或值得嚮往的工作指派。獎賞權是強制權的鏡像：一個給糖，一個給棒。

+ [ 03／LEGITIMATE ]

合法權

LEGITIMATE POWER

來自於可以掌握並使用組織資源的正式職權，是正式權力中範圍最廣的一種。成員接受職權階層，便是接受了合法權的基礎。

個人權力的兩種類型

PERSONAL POWER
[ 2 TYPES ]
+ [ 01／EXPERT ]

專家權

EXPERT POWER

藉由專業技術、特殊技能或知識來發揮影響力。這種權力來自於個人的專業能力和經驗。知識經濟時代，專家權的份量與日俱增。

+ [ 02／REFERENT ]

參考權

REFERENT POWER

基礎為某人擁有令人渴望的資源或個人特質。這種權力來自於他人對個人的尊敬和讚賞。名人代言正是參考權的商業運用。

依賴性：權力的關鍵

DEPENDENCE: THE KEY TO POWER
[ 3 POINTS ]
+ [ 01／POSTULATE ]

基本假設

GENERAL DEPENDENCE POSTULATE

若B愈依賴A，則A對B的權力愈大。這條通則是理解組織權力關係的起點。

+ [ 02／CONTROL ]

控制資源

RESOURCE CONTROL

當個體獨自控制他人所欲求的資源時，他人便會對其產生依賴。獨占是關鍵：可以被繞過的資源，換不到權力。

+ [ 03／ALTERNATIVES ]

選擇多樣性

ALTERNATIVES

可選擇的替代方案愈多，愈能避免受他人控制。多元的技能與人脈，是個人降低被支配的最佳保險。

09

創造依賴性的因素

WHAT CREATES DEPENDENCE?
[ 3 FACTORS ]
+ [ 01／IMPORTANCE ]

重要性

IMPORTANCE

資源對他人的重要程度。若沒有人對所控制的資源有所求，依賴性即不存在。能化解組織關鍵不確定性的部門，權力自然最大。

+ [ 02／SCARCITY ]

稀少性

SCARCITY

資源稀少程度與依賴性成正比，可進一步由各類職業的權力情況看出。人才市場上供不應求的職能，議價能力隨之水漲船高。

+ [ 03／NONSUB ]

不可替代性

NONSUBSTITUTABILITY

資源愈沒有替代品，控制者的權力愈大。人工智慧的發展正使部分技能逐漸變得可被替代。

正式小團體網絡

FORMAL SMALL-GROUP NETWORKS
[ 3 TYPES ]
正式的組織網絡可能相當複雜，資訊沿著網絡流動，對組織中的權力與影響力具有重大意涵。常見的小團體網絡可濃縮為三種類型。
+ [ 01／CHAIN ]

鏈型

CHAIN

嚴格遵循正式的指揮鏈，近似於層級嚴明之三層式組織中的溝通管道。

+ [ 02／WHEEL ]

輪型

WHEEL

依賴一位居中的人物作為所有溝通的樞紐，近似於由管理者主導的工作團體。居中的角色享有多元資訊、支持與較高的權力和地位。

+ [ 03／ALL-CHANNEL ]

全方位型

ALL-CHANNEL

允許所有成員彼此積極溝通，常見於自我管理團隊，沒有單一的領導角色。許多組織以此為理想型態。

社會網絡分析

SOCIAL NETWORK ANALYSIS
[ 4 POINTS ]
+ [ 01／DEFINITION ]

定義

社會網絡分析（social network analysis）是評估組織內部資源交換及依賴性的工具。

+ [ 02／FUNCTION ]

功能

檢視組織成員間的溝通型態，確認資訊如何流動。節點（node）之間的連結稱為連帶（tie），頻繁交換資源者具有強連帶。

+ [ 03／SOCIOGRAM ]

社會關係圖

社會關係圖（sociogram）描述社會網絡中個體間相互關係，如同非正式版本的組織圖。

+ [ 04／BROKER ]

比較與中介者

正式組織圖顯示職權應該如何流動，社會關係圖顯示資源的實際流動。居於中介位置者（broker）因掌握不同群體的獨特資源而擁有較大權力。

權力戰術（一）

POWER TACTICS
[ 01-04／09 ]
權力戰術（power tactics）是運用權力影響他人的具體方法，是管理者在組織中發揮影響力的重要工具。共有九種主要的權力戰術。
+ [ 01／LEGITIMACY ]

合法

LEGITIMACY

依據自己的職位或組織政策來要求他人遵從，通常用於正式的組織架構中，效果取決於職位權力的強度。

+ [ 02／RATIONAL ]

理性說服

RATIONAL PERSUASION

使用邏輯論證和事實證據來說服他人，是最普遍且專業的影響方式，特別適用於專業性的決策過程。

+ [ 03／INSPIRATIONAL ]

鼓舞式訴求

INSPIRATIONAL APPEALS

訴諸他人的價值觀、理想和抱負，激發熱情和承諾，特別適合在推動變革或重大專案時使用。

+ [ 04／CONSULTATION ]

商議

CONSULTATION

邀請他人參與決策過程，讓其提供建議和意見，可以增加決策的接受度和承諾度。

權力戰術（二）

POWER TACTICS
[ 05-09／09 ]
交換EXCHANGE
提供利益交換或互惠條件來獲得支持，建立在互利的基礎上，但需要確保交換的公平性。
個人式訴求PERSONAL APPEALS
基於友誼或私人關係請求支持，依賴良好的人際關係，但需謹慎使用以避免濫用友誼。
逢迎INGRATIATION
通過讚美或友好行為來取得他人好感，需要真誠，過度使用可能產生反效果。
施壓PRESSURE
使用要求、威脅或持續檢查來達成目標，是較強制性的戰術，可能產生負面影響，應審慎使用。
聯盟COALITIONS
尋求他人支持來強化影響力，通過集體力量實現目標，但需要妥善管理各方利益。

情境 1：績效考核結果溝通與說服

COMMUNICATING APPRAISAL RESULTS
[ SCENARIO ]
+ [ 背景描述 ]

你是公司 HR 部門的小主管，剛協助完成年度績效考核報告，並將結果提交給各部門主管審核。經過討論後，某些員工因為績效未達標，被評為需要改進或表現不佳。當這些員工收到評估結果時，立即對考核標準和流程提出質疑，認為主管未充分考量他們的實際貢獻，例如臨時支援其他專案或超時工作等努力。此外，員工之間開始私下討論，質疑考核的公平性，甚至有人威脅要向勞動部檢舉。主管要求你協助處理這些員工的抱怨與質疑，安撫情緒，並說服他們接受考核結果，同時確保此事件不會影響團隊士氣和信任關係。

補充研究：開放式人格測驗比量表更難造假

FAKING ON OPEN-ENDED PERSONALITY ASSESSMENTS ── SPEER ET AL.
[ JAP 2026 ]
N＝2,039／7 LLMS
求職者的印象管理會讓人格量表分數膨脹。同一批人在誠實與求職兩種指示下作答：量表分數的上移為 d̄＝.65，以自然語言處理評分的開放式書寫題只有 d̄＝.26；AI 代寫的回答分數通常高於真人，但客製化的偵測模型可近乎完全辨識，誤判率 1%。
+[ 01／PUZZLE ]

造假在書寫題裡怎麼發生

  • 自陳量表的造假是甄選的老問題；開放式測驗要求受測者用文字描述自己，被認為較難造假
  • 論文提出兩種書寫層次的印象管理：精心鋪陳（elaborate responding）與選擇性揭露（只講好的、不講壞的）
  • 對照印象管理的八種技巧：選擇性揭露就是自我推銷與誇大的文字版
[ 02／DESIGN ]

資料與方法

  • 2,039 名成人隨機分派誠實作答或求職指示（假設正在應徵一份很想要的工作），3 至 7 天後再誠實填量表
  • 466 份書寫回答由專家評精心鋪陳與選擇性揭露的程度；全部回答以自然語言處理評分
  • 另比較七種大型語言模型生成、以及人機混合改寫的回答
[ 03／FINDINGS ]

主要發現

  • 求職指示下精心鋪陳 d＝.29、選擇性揭露 d＝.72 都上升；特質較高者更會鋪陳與挑好話講
  • 造假的分數上移：量表 d̄＝.65，開放式題 d̄＝.26；評分模型若改以人工評分訓練，上移回到 .63
  • 訓練樣本混合誠實與求職回答時抗造假性最好；AI 回答分數高但可被辨識
[ 04／IMPLICATIONS ]

對甄選與印象管理的意涵

  • 印象管理不會消失，但可以用題型與評分方式壓低它的報酬
  • 抗造假性來自評分模型的設計，不是題型本身：模型學什麼，就會獎勵什麼
  • AI 代寫是新的印象管理管道，偵測層是甄選公平性的必要配備
造假的報酬取決於評分怎麼設計，開放式書寫加自然語言處理評分把報酬壓到量表的四成
