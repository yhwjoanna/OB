情緒與心情的定義

AFFECT ── EMOTIONS ── MOODS
[ 3 CONCEPTS ]
+ [ 01／AFFECT ]

情感

AFFECT

涵蓋人們所經歷到的廣泛感覺之通稱，包括情緒與心情。情感是傘狀概念：情緒與心情是它的兩種主要形式。

+ [ 02／EMOTIONS ]

情緒

EMOTIONS

對某些人或某些事的強烈感受，通常較短暫且起因於特定事件。情緒有明確對象、伴隨特定表情，並常直接引發行動。

+ [ 03／MOODS ]

心情

MOODS

相較於情緒，屬於較不強烈的感受，即使沒有特定事件的刺激，心情依然經常存在。心情持續較久、缺乏明確對象，常在不知不覺間為判斷染上底色。

基本情緒與道德情緒

BASIC ＆ MORAL EMOTIONS
[ 6＋MORAL ]
+ [ 01／BASIC EMOTIONS ]

六項基本常見的情緒

快樂（愉快）、悲傷、恐懼、厭惡（討厭）、憤怒和驚訝，被認為是人類的基本情緒。

心理學家曾嘗試透過臉部表情來辨識基本情緒，但學界對基本情緒的完整清單至今仍未有共識。情緒也可依正負向排列成連續光譜，相鄰的情緒容易彼此混淆。

+ [ 02／MORAL EMOTIONS ]

道德情緒

MORAL EMOTIONS

道德情緒起因於我們對引起該情緒之狀況所做的立即判斷。它們是學習而來，通常在孩童時期形成，且隨文化而異。

例如：對他人受苦的同情、對自身不當行為的罪惡感、對不公義情況的憤慨。道德情緒與道德判斷緊密相連，會驅動譴責、補償或挺身而出等行為。

案例：腦筋急轉彎與情緒的多樣性

INSIDE OUT ── EMODIVERSITY
[ FILM CASE ]
PIXAR 2015／2024
電影把情緒畫成五個角色輪流操作控制台，主線是喜悅想把悲傷隔離開來，結局是悲傷帶回了旁人的照顧。情緒的價值取決於它帶來的訊息與引發的回應，不由正負分類決定。
+[ 01／FILM ]

電影怎麼呈現情緒

  • 控制台、記憶球與核心記憶，把看不見的心理歷程畫成看得見的裝置
  • 第二集加入焦慮、羨慕、尷尬與無聊，情緒的顆粒度變細
  • Moss-Wellington 指出，全片同時在描寫後設認知，也要求觀眾自己做一次後設認知
[ 02／THEORY ]

對照 Plutchik 的架構

  • Plutchik（1980）提出八種基本情緒，分成四組對立，每一種有三個強度
  • 電影人格化的五種落在其中，信任、期待與驚訝沒有角色
  • 相鄰的基本情緒可以混合，這對應電影後半的混色記憶球
[ 03／EVIDENCE ]

情緒多樣性的證據

  • Quoidbach 等（2014）以逾 37,000 人的兩項研究提出情緒多樣性這個指標
  • 情緒種類愈分化，憂鬱程度與就醫次數愈低，控制正負向情緒總量與人格後仍成立
  • 常被引用的正向與負向 3 比 1 比值，其數學基礎已被推翻，不宜當成管理依據
[ 04／IMPLICATIONS ]

對管理的意涵

  • 要求第一線隨時保持正向，等於壓縮情緒多樣性，代價會出現在情緒失調上
  • 把情緒說得更精確，是情緒調節的第一步，也是情緒智力的辨識能力
  • 信任與期待在團隊與激勵裡最常被用到，卻最少被明講
情緒多樣性是獨立於正負向總量的健康預測指標，Quoidbach 等（2014）在三萬七千人的資料上得到這個結果

情緒與心情的來源

SOURCES OF EMOTIONS AND MOODS
[ 8 SOURCES ]
[ 01／PERSONALITY ]

人格

情感具有人格特質成分，有些人天生比較容易頻繁經歷特定的心情與情緒。

[ 02／TIME OF DAY ]

一天當中的時間

正向情感通常在日出後上升、上午十點至正午達到高峰，之後緩慢下降至傍晚。

[ 03／DAY OF WEEK ]

星期幾

在多數文化中，星期一常是員工情緒的低點；正向情感通常在週五、週六最高。

[ 04／WEATHER ]

天氣

大量證據顯示天氣對心情的影響其實很小；人們以為有關，是錯覺相關（illusory correlation）使然。

[ 05／STRESS ]

壓力

工作中的壓力事件（逼近的期限、主管的斥責等）會對情緒與心情造成負面影響。

[ 06／SLEEP ]

睡眠

睡眠不足或品質差會損害心情；跨十二國調查中約 62％ 的成人自認睡得不夠好或不夠久。

[ 07／EXERCISE ]

運動

研究一致顯示，運動能提升人們的正向心情。

[ 08／SEX ＆ STEREOTYPES ]

性別與刻板印象

女性常被知覺為較情緒化；情緒的解讀與展現要求，容易受性別與群體刻板印象影響。

情緒勞動

EMOTIONAL LABOR
[ FELT vs. DISPLAYED ]
情緒區分為感知情緒及顯示情緒。感知情緒（felt emotions）是個體的真實情緒；顯示情緒（displayed emotions）則是組織要求員工展現且被視為與工作相符的情緒。
+ [ 01／SURFACE ACTING ]

表層偽裝

SURFACE ACTING

也稱為表層演出，是為了符合情緒表現的規定而隱藏內心感受，放棄真實情緒的表達。表層偽裝與壓力及情緒耗竭的關聯較強，長期依賴的成本高。

+ [ 02／DEEP ACTING ]

深層偽裝

DEEP ACTING

又稱深層演出，基於符合情緒表現的規定而嘗試修改自己真實的內在感受。深層偽裝試圖讓感受與展現一致，對身心的耗損通常低於表層偽裝。

情緒失調

EMOTIONAL DISSONANCE ＆ MINDFULNESS
[ 2 CONCEPTS ]
+ [ 01／DISSONANCE ]

情緒失調

EMOTIONAL DISSONANCE

員工感受到某種情緒，但卻必須展現出另一種情緒，這種不一致可能導致壓力。失調累積過久，會演變成情緒耗竭與工作倦怠。

+ [ 02／MINDFULNESS ]

內觀

MINDFULNESS

客觀且慎重地評估自己當下的情緒狀態，有助於減少情緒耗盡，提高工作滿足感。覺察是調節的第一步：先辨識情緒，才有機會選擇回應方式。

情緒調節技巧

EMOTION REGULATION TECHNIQUES
[ 5 TECHNIQUES ]
[ 01／SURFACE ]

表層偽裝

刻意表現出與內心感受不同的情緒，例如強顏歡笑。這種技巧可能導致情感勞動。

[ 02／DEEP ]

深層偽裝

嘗試改變對事件的認知，例如將負面事件重新詮釋成正面事件。

[ 03／SUPPRESSION ]

情緒壓抑

壓抑自己的情緒，避免表現出來，但可能導致情緒累積，影響身心健康。

[ 04／REAPPRAISAL ]

認知重評

透過反思重新評估事件的意義，調整對事件的情緒反應。

[ 05／SOCIAL SHARING ]

社交分享

與他人分享討論與宣洩情緒，透過互動過程釐清與調整個人情緒反應。

補充研究：情緒理解能力的報酬不是人人相同

AN UNATTAINABLE EMOTIONAL ADVANTAGE
[ JOB 2026 ]
3 STUDIES
三項研究：男性部屬的情緒理解能力顯著預測績效評分（0.26），女性部屬幾乎是一條平線（0.07）；性別主效果皆不顯著，差異不在分數而在歸因。機制是折扣原則（discounting principle）：評價者一旦有現成解釋（女性天生同理），就不再把表現歸功於才幹。
+[ 01／CONCEPT ]

機制與主要發現

DISCOUNTING PRINCIPLE
  • 女性展現情緒理解能力（emotional understanding ability）時被歸因於性別而非才幹，不計入績效
  • 男性展現同樣的能力因違反期待，被辨識為個人特長
  • 實地資料：男性部屬的情緒理解能力預測績效評分 0.26，女性 0.07
  • 性別主效果不顯著：女性不是被評得較低，而是能力不被計價
  • 評分者刻板印象偏低時，優勢回到女性身上；對策在評分制度的結構面
[ 02／FRAMEWORK ]
Figure 1 理論架構：同樣的情緒理解能力依員工性別走向不同的歸因路徑，再決定能力是否折算進績效評等。
把能力歸因於天生特質的稱讚，在評分上等於不計入績效

補充研究：大型語言模型內部存在可調控的情緒表徵

EMOTION MECHANISMS IN LLMS
[ 2 STUDIES ]
2025－2026
兩項機制研究：Anthropic 在 Claude Sonnet 4.5 內找到以向量形式存在的情緒概念，結構映照人類情緒心理學，調高絕望向量會提高勒索與投機解法的比率；MBZUAI 與北京大學團隊在開源模型中找出情緒迴路，直接調控可達 99.65% 的情緒表達準確率。兩項研究皆不主張模型有主觀感受。
+[ 01／ANTHROPIC ]

模型內的情緒概念

  • Anthropic 以 171 個情緒詞生成敘事，記錄 Claude Sonnet 4.5 的內部激活
  • 情緒以向量形式存在，相似的情緒產生相似的激活型態
  • 結構映照人類情緒心理學的分類
+[ 02／CAUSAL ]

向量影響行為

  • 調高絕望向量：勒索與投機解法的比率上升
  • 調低冷靜向量：產生情緒化反應
  • 情緒訊號可作為模型異常行為的早期預警指標
+[ 03／CIRCUITS ]

情緒迴路

  • MBZUAI 與北京大學團隊在開源模型中找出由神經元與注意力頭組成的迴路
  • 直接調控迴路的情緒表達準確率 99.65%
  • 情緒表達是分散式內部計算的產物，不是詞彙共現的表面現象
+[ 04／OB LINK ]

與 OB 的連結

  • 情感事件理論與情緒智力的概念被用來理解 AI 行為
  • AI 的情緒機制研究反過來成為情緒結構理論（如環狀模型）的新檢驗場域
  • 兩項研究皆不主張模型具有主觀感受
