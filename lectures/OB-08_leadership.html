領導（leadership）的定義

WHAT IS LEADERSHIP?
[ 4 POINTS ]
[ 01／INFLUENCE ]

影響力

領導是影響團體達成願景或目標的能力。影響力的來源可以是正式職位，也可以來自個人本身。

[ 02／INFORMAL ]

非正式領導

非制式領導來自組織正式結構之外的影響能力，同樣重要，甚至常比正式職權的影響更為深遠。

[ 03／MANAGEMENT ]

管理與領導

並非所有的領導者都是管理者，也並非所有的管理者都是領導者。管理處理複雜、維持秩序；領導處理變革、指引方向。

[ 04／EFFECTIVENESS ]

組織效能

組織為了達成理想效能，必須具備強而有力的領導與管理，兩者相輔相成、缺一不可。

特質理論

TRAIT THEORIES OF LEADERSHIP
[ 3 POINTS ]
+[ 01／DEFINITION ]

定義

聚焦於個人特質，試圖找出區分領導者與非領導者的人格、社會、身體或智能屬性。這是領導研究最早的取向，可追溯至偉人理論的傳統。

+[ 02／FINDINGS ]

主要發現

外向是能否成為有效領導者的最重要特質，但與預測領導者效能相比，外向與領導者「產生」的關聯更強烈。

+[ 03／OTHERS ]

其他重要特質

勤勉盡責與外向皆與領導者的自我效能有正面關聯。多數人希望追隨一個有自信帶領大家往正確方向邁進的領導者。

特質理論的結論

CONCLUSIONS ON TRAIT THEORIES
[ 2 SIDES ]
+ [ 01／PREDICTION ]

預測能力

特質的確能預測領導。特質在預期領導者浮現及領導風格呈現上，比起實際區分有效與無效領導者方面，有較佳貢獻。換句話說：特質較能預測誰會出線，較難預測誰做得好。

+ [ 02／LIMITS ]

侷限性

特質理論可以協助預測領導，但無法完全解釋領導。這促使研究者轉向探討行為理論，以進一步界定領導者的表現。行為理論的重要意涵：領導若是行為，就可以被訓練與學習。

07

倡導結構與體恤

INITIATING STRUCTURE ＆ CONSIDERATION
[ 2 DIMENSIONS ]
+ [ 01／STRUCTURE ]

倡導結構

INITIATING STRUCTURE

領導者在尋求目標達成當中，為定義和建構自己與部屬之角色時所做的行為，涉及任務分配、目標設定和績效標準的建立。倡導結構與團體及組織層次的生產力密切相關。

+ [ 02／CONSIDERATION ]

體恤

CONSIDERATION

領導者願意和部屬建立互相信任、尊重部屬意見，以及注重部屬感受的工作關係，包括關心員工福祉、提供支持和鼓勵。體恤與部屬的滿意度、激勵及領導者的受尊敬程度關聯較強。

權變理論簡介

CONTINGENCY THEORIES
[ 3 POINTS ]
+[ 01／CORE ]

核心思想

不同情況下需要不同的領導風格：在情況 A 之下風格 X 是合適的，而風格 Y 則較適合情況 B，風格 Z 則應該配合情況 C。

+[ 02／MODELS ]

主要模式

包括 Fiedler 權變模式、情境領導理論、路徑-目標理論和領導者-參與模式。各模式對情境的界定不同，但共同主張：沒有放諸四海皆準的領導風格。

+[ 03／MEANING ]

理論意義

試圖解釋領導效能如何受到特定情境因素的影響，為領導實踐提供更靈活的指導。

情境領導理論（SLT）

SITUATIONAL LEADERSHIP THEORY
[ 3 POINTS ]
+[ 01／CORE ]

核心思想

聚焦在被領導者身上。成功的領導取決於是否選擇對的領導風格，亦即須視部屬的準備度或其完成特定任務的意願與能力而定。

+[ 02／STRENGTHS ]

優點

有直覺上的吸引力，確認了被領導者的重要性，並將邏輯建築在領導者可以彌補被領導者在能力與激勵程度上的限制。依部屬準備度搭配指導型、推銷型、參與型或授權型風格。

+[ 03／LIMITS ]

侷限性

模式本身模糊、不一致，以及測試理論的研究方法有問題，影響了理論的實際應用價值。

路徑-目標理論

PATH-GOAL THEORY
[ 4 POINTS ]
[ 01／BASIS ]

理論基礎

主要原理是從倡導結構與體恤而來，並結合激勵的期望理論。

[ 02／ROLE ]

領導者角色

有效能的領導者應該幫助部屬釐清可以達成目標的途徑，並減少途中的障礙，使其能順利完成目標。

[ 03／SITUATION ]

情境適應

領導者所採取之領導行為，端視情境的複雜度而定。例如當任務不明確時，指導式領導可能更有效。

[ 04／DIFFERENCES ]

個別差異

考慮到部屬的個別差異，如積極設定目標的領導者能幫助認真盡責的部屬成就高績效。

領導者-成員交換理論（LMX）

LEADER-MEMBER EXCHANGE THEORY
[ 3 POINTS ]
+[ 01／CORE ]

理論核心

由於時間的壓力，領導者會和部屬中的某一小團體建立特別關係。這些人組成內團體，受到領導者的信任與更多關注，並擁有不少特權；其餘部屬則落入外團體。

+[ 02／SELECTION ]

選擇標準

領導者會依部屬的人口統計變項、態度和人格特質與其相似，或因為比外團體成員更具勝任能力而加以挑選；這種選擇並非隨機。

+[ 03／EFFECTS ]

影響

內團體部屬將獲得較高的績效評估、對上司滿意度較高、較可能產生公民行為；但差別待遇也可能對組織整體氛圍產生負面影響。

魅力型領導

CHARISMATIC LEADERSHIP
[ 4 POINTS ]
[ 01／DEFINITION ]

定義

跟隨者在看到特定行為時，會將之歸因為英雄式或非凡型的領導能力，並因而賦予這些領導者權力。

[ 02／TRAITS ]

特質

具有願景、願意承擔風險、敏銳察覺部屬需求，能表現出超乎尋常的行為。

[ 03／EFFECTS ]

影響

希臘最近的研究認為，魅力型領導可以透過在追隨者中建立共同的團體認同，提升追隨者的組織認同（承諾）。

[ 04／LEARNABLE ]

培養

魅力可以通過學習和實踐來培養，如使用生動的語氣、眼神接觸和表情來強化訊息，並激發追隨者的潛能。

魅力型領導的情境因素

SITUATIONAL FACTORS
[ 4 FACTORS ]
[ 01／CRISIS ]

危機情境

當人們感受到危機、面對壓力或擔憂生活時，更能接受魅力型領導。在這些情況下，魅力型領導者可以提供方向和希望。

[ 02／STRESS ]

壓力緩解

魅力型領導者可以協助員工減輕壓力，因為他們能讓工作看起來更有趣也更有意義。

[ 03／LEVEL ]

組織層級

魅力型領導在組織高層較顯重要，但就組織橫向水平運作上，也可從遠端或近距離發揮其效能。

[ 04／INDIVIDUAL ]

個人差異

有些人的人格特質就是特別容易受到魅力領導的影響，效果可能因追隨者的個性而異。

魅力型領導的陰暗面

THE DARK SIDE OF CHARISMA
[ 3 POINTS ]
+[ 01／SELF-INTEREST ]

個人主義

許多魅力型領導者會把個人目標放在組織目標之上，這種自私的行為可能損害組織的長期利益。

+[ 02／NARCISSISM ]

自戀傾向

自戀的人，部分行為與魅力型領導有高度相關，可能導致領導者忽視他人的需求和意見。組織給予魅力型執行長的高薪與寬容，也可能放大這些風險。

+[ 03／BALANCE ]

平衡觀點

魅力型領導整體而言仍有其效果，只是它不是永遠的答案，其效果需要根據具體情況來評估。

交易型領導與轉換型領導

TRANSACTIONAL vs. TRANSFORMATIONAL
[ 6 DIMENSIONS ]
在 Bass 的全範圍模型中，交易型與轉換型是同一份行為清單上的不同段落，同一位領導者可以同時使用兩者。
面向交易型領導（transactional）轉換型領導（transformational）
定義澄清角色與工作要求，據此引導並激勵部屬促使部屬把組織利益置於個人私利之上，並對其產生超出職務的影響
核心機制明確的交換：講清楚標準，達標給獎賞改變部屬的目標與自我概念，使其認同組織
主要行為權宜獎賞、積極與消極的例外管理理想化影響、鼓舞激勵、智能激發、個別關懷
對部屬的假設依外在誘因行動可被願景與認同驅動
典型效標角色內績效、短期目標達成額外努力、組織公民行為、變革與創新
常用測量兩者皆取自多因素領導問卷（Multifactor Leadership Questionnaire, MLQ）的不同分量表
兩者的差別在於交換的是報酬，還是目標本身

交易型和轉換型領導的特徵

CHARACTERISTICS
[ 4＋4 ]
+ [ 01／TRANSACTIONAL ]

交易型領導特徵

  • 權宜獎賞：訂有努力即獎賞的合約。
  • 積極的例外管理：監視並搜尋偏離規則和標準的活動。
  • 消極的例外管理：只有在不符標準時才介入。
  • 放任主義：放棄責任，避免做決策。
+ [ 02／TRANSFORMATIONAL ]

轉換型領導特徵

  • 理想化的影響：提供願景和使命感，灌輸自尊心。
  • 智能激發：提升智慧、理性和謹慎解決問題的能力。
  • 鼓舞激勵：溝通高度的期望，用象徵匯集努力。
  • 個別關懷：給予個別的關注，個別對待每名員工。

交易型和轉換型領導的關係

COMPLEMENTARY, NOT OPPOSING
[ 4 POINTS ]
[ 01／COMPLEMENT ]

互補關係

交易型和轉換型領導不應被視為完成任務的對立方法，兩者應該是互補的。

[ 02／BEST ]

最佳領導者

最佳領導者應該兼具交易型和轉換型特色，這種結合可以在不同情況下發揮最大效果。

[ 03／PERFORMANCE ]

績效提升

轉換型領導是建立在交易型領導之上：其所產生的部屬努力與績效水準，超過了僅用交易型方法時所擁有的。

[ 04／FULL RANGE ]

全範圍領導

全範圍的領導模式強調領導者應該能夠靈活運用不同的領導風格，以適應不同的情境需求。

邀請部屬建言，未必換來建言

VOICE SOLICITATION
[ 2 PATHWAYS ]
建言徵詢（voice solicitation），也就是主管開口徵詢部屬意見，一向被視為正向行為；但同一句邀請會依部屬對主管的知覺，走上兩條方向相反的路徑。
+[ 01／CONCEPT ]

同一句邀請，兩套反應系統

APPROACH–AVOIDANCE

趨近與迴避系統理論（approach–avoidance systems theory）主張人對機會與威脅各有一套反應系統。徵詢本身是中性的，啟動哪一套取決於部屬知覺到的主管支配性（leader dominance）：低支配時讀成機會，啟發感（inspiration）上升帶動建言；高支配時讀成模糊威脅，難以判斷是真心邀請或忠誠測試，焦慮上升導向沉默。

  1. 高支配情境下，啟發感這條路徑完全關閉（p = .453），焦慮那條路徑同時被打開。
  2. 主管聲望只能放大啟發感，無法化解支配性引發的焦慮：受人敬重不等於能抵銷支配性的作用。
  3. 意涵：風格強勢者若要徵詢，得先把邀請的意圖講到不留模糊空間。

  1. 願景過於宏大，可能引發疑慮。
  2. 須平衡短期目標與長期願景。
[ 03／AUTHENTIC ]

真誠領導

  1. 須平衡自我披露與專業領域的差異。
  2. 須確保價值觀一致，避免分歧。
[ 04／SERVANT ]

僕人式領導

  2. 避免依賴感情維繫影響客觀決策。

挑戰領導的觀點：歸因與替代品

ATTRIBUTION THEORY OF LEADERSHIP ── SUBSTITUTES ＆ NEUTRALIZERS
[ 2 CHALLENGES ]
兩個觀點質疑領導的實際作用：歸因理論主張領導是人們對結果的解釋，不是原因；替代品理論主張某些個人、工作與組織特徵可以取代或抵銷領導者的影響。
+[ 01／ATTRIBUTION ]

領導的歸因理論

  • 領導是一種知覺：人們把智力、外向、口才、進取、理解力、勤奮歸給被視為領導者的人
  • 組織績效極好或極差時，人們傾向歸因於領導者，而非市場或運氣
  • 看起來像領導者的人（果斷、堅持、言行一致）更容易被歸類為有效的領導者
  • 意涵：領導效能的評價有一部分是印象管理的結果，對照 OB-9 的印象管理
+[ 02／SUBSTITUTES ]

領導的替代品與中和物

特徵對關係導向領導對任務導向領導
個人：經驗與訓練無影響替代
個人：專業取向替代替代
個人：對獎酬冷淡中和中和
工作：高度結構化無影響替代
工作：自帶回饋無影響替代
工作：本身令人滿足替代無影響
組織：明確正式的目標無影響替代
組織：僵硬的規則程序無影響替代
組織：凝聚力強的團體替代替代
替代品讓領導者的行為變得多餘，中和物讓領導者的行為失效；兩者都提醒領導效果有其邊界

尋找與培養有效的領導者

SELECTING ＆ TRAINING LEADERS
[ 2 ROUTES ]
組織取得有效領導者的兩條路：甄選時辨識，任用後訓練。兩條路的證據都指向同一件事：可訓練的是具體行為，不是人格。
+[ 01／SELECTING ]

甄選

  • 先界定職位需要的領導型態，再對照候選人：情境不同，適合的領導者不同
  • 人格測驗可辨識外向性、勤勉盡責性、開放性；高自我監控者較能依情境調整行為
  • 情緒智力（OB-5）與魅力型領導的效能相關
  • 面試與評鑑中心可觀察候選人在模擬情境中的實際行為，比自陳可靠
+[ 02／TRAINING ]

訓練

  • 訓練對高自我監控者較有效，因為他們更能把學到的行為調整到情境中
  • 可訓練的內容：建立信任、師徒指導、情境分析（分析情境、調整風格）
  • 魅力型行為可以教：表達願景、以身作則、傳達高期望與信心；轉換型領導技巧的訓練也有效果證據
  • 訓練的限制：對缺乏基本特質（如低外向、低情緒穩定）者效果有限
甄選看特質與情境的配對，訓練教可觀察的行為

不當督導

ABUSIVE SUPERVISION
[ 4 POINTS ]
[ 01／DEFINITION ]

定義

指主管在持續性的日常互動中，以敵意、貶抑或羞辱方式對待部屬，例如公開嘲諷、冷暴力與刻意孤立。

[ 02／SCOPE ]

範疇

此行為不涉及肢體暴力，但對部屬身心健康、工作態度與績效的傷害同樣深遠。

[ 03／CATEGORY ]

學術上的分類

這是一種破壞性領導（destructive leadership）的形式，與部屬的偏差行為、離職傾向及家庭衝突相關。

[ 04／CORE ]

核心特徵

其核心在於長期、反覆且負面的非身體行為；組織應建立申訴管道並追究管理責任。

不當督導的常見行為類型

COMMON ABUSIVE BEHAVIORS
[ 6 TYPES ]
[ 01 ]

公開羞辱

在公開場合嘲諷、譏笑或貶低員工，損害其尊嚴。

[ 02 ]

無理批評

對員工努力和成果進行無端批評或全盤否定，打擊積極性。

[ 03 ]

情緒不穩

主管情緒化，常以怒吼或冷暴力回應，造成工作環境壓力。

[ 04 ]

刻意排擠

無視、孤立或排斥員工，使其感到被邊緣化或不受重視。

[ 05 ]

情緒勒索

提出不合理要求，並以情感施壓或威脅方式迫使部屬順從。

[ 06 ]

功過歸屬不公

將部屬的成功歸為己有，而將錯誤或失敗完全推卸給部屬。

這些行為會對員工的心理健康、工作滿意度和組織承諾產生嚴重負面影響，最終損害團隊績效和組織穩定

[ 5 POINTS ]

補充研究：徒弟不開口求教，是怕成為負擔

THE INEQUITY ILLUSION OF ADVICE SEEKING ── BURMEISTER & LEVIN
[ AMJ 2026 ]
9 STUDIES／2 FIELD EXPERIMENTS
求教者常把交換看成單向：自己得到幫助，對方賠上時間與精力，論文稱為求教的不公平錯覺（inequity illusion），伴隨的情緒是負擔焦慮（burden anxiety）。九項研究顯示，讓求教者先想到給建議者的收穫，求教行為就增加。
+[ 01／PUZZLE ]

為什麼單靠鼓勵不夠

  • 常見作法強調求教者的好處：人脈、資訊、機會、升遷；訊息本身正確，但沒碰到情緒障礙
  • 不公平錯覺讓分析師不問資深主管、求職者跳過資訊訪談、新人寧可獨自摸索
  • 對方地位愈高、彼此愈不熟，錯覺愈強，重新框架的效果也愈大
[ 02／MECHANISM ]

給建議者的收穫

  • 覺得有用，專業被看重
  • 學到新東西，建立有價值的連結
  • 順帶反思自己的處境
  • 與志同道合者交談的活力與樂趣
[ 03／PRACTICE ]

主管與制度端的作法

  • 把求教框架成雙方創造價值；說明被求教者會覺得受尊重、有用、有活力
  • 訓練求教者說出為何選擇這位對象，讓請求同時傳達專業肯定
  • 資深者分享因給建議而獲益的經驗；主管在日常工作中示範求教
  • 把這套語言寫進入職、師徒制、內部專家名錄、職涯工作坊與領導發展課
[ 04／MENTORING ]

對師徒制的意涵

  • 徒弟不敢占用師父時間是常見的失效點；配對說明寫明師父的收穫，是成本最低的介入
  • 地位差距最大的配對（高階主管帶新人）最需要這種框架
  • 師父的角色是肯定徒弟自己的理想我，不是把徒弟雕成自己的樣子；伴侶研究顯示強加自身理想反而降低關係品質（Michelangelo 現象）
有效的制度不只提供接觸專家的管道，也降低使用管道的情緒成本
